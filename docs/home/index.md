# Sparkive

An archive of things that spark my interest.

I'm Tom Olsen. Sparkive is my collection of lessons about algorithms, mathematics, physics, and other topics I enjoy learning. My aim is to explain the reasoning behind each idea, work through the important steps, and make the result useful both for learning and as a reference.
